# Quiz Management System

A simple console-based Quiz Management System developed using Python. The system provides separate functionalities for Admin and Students. Admins can manage quizzes and questions, while students can register, attempt quizzes, and view their scores.

## Features

### Admin Module
- Admin login authentication
- Add new quizzes
- Add questions to quizzes
- View quizzes and questions
- Delete questions
- Modify questions
- View student scores

### Student Module
- Student registration
- Student login
- View available quizzes
- Select and attempt quizzes
- Automatic score calculation
- Store student quiz scores

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input
- Basic Authentication

## How It Works

### Admin Workflow

     ↓
Admin Menu
     ↓
Add Quiz / Add Questions
     ↓
View / Modify / Delete Questions
     ↓
View Student Scores

### Student Workflow

Student Registration/Login
        ↓
View Available Quizzes
        ↓
Select Quiz
        ↓
Answer Questions
        ↓
Calculate Score
        ↓
Display Score
        ↓
Store Score
